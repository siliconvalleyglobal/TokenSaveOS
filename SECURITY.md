# Security Policy

## Reporting a Vulnerability

**SILICON VALLEY GLOBAL PH INC** takes the security of TokenSaveOS seriously.

If you discover a potential security vulnerability in TokenSaveOS, please report it privately to our security team before public disclosure.

- **Email:** security@svgph.com
- **Response Time:** We will acknowledge receipt within 24 hours and provide an estimated resolution timeline.

Please do not open public GitHub issues for security vulnerabilities.
